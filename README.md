# EDGE-FIRE AI 데이터 준비

Colab에서 산불 이미지 데이터의 폴더 구조와 라벨을 점검하기 위한 시작 프로젝트입니다. 원본 이미지와 라벨은 Google Drive에 보관하고, 이 저장소에는 코드와 문서만 관리합니다.

## 시작하기

1. AI Hub에서 승인된 데이터만 내려받고 압축을 풉니다. 전체 원천 이미지 대신 프로젝트에 필요한 작은 샘플을 팀에서 별도로 마련하는 것을 권장합니다.
2. Google Drive에 `EDGE-FIRE/data/raw` 폴더를 만들고, 받은 파일이나 샘플을 둡니다.
3. Colab에서 `notebooks/01_data_inventory.ipynb`를 열고 Drive를 연결합니다.
4. 노트북의 `DATA_ROOT`를 실제 데이터 폴더로 수정한 다음 셀을 위에서부터 실행합니다.

## 현재 범위

- Drive 폴더 확인 및 상위 파일 목록 출력
- 폴더 내 파일 종류별 개수와 제한된 파일 샘플 목록 확인
- JSON 라벨 구조와 이미지-라벨 연결 상태 점검을 위한 시작 코드
- 이미지 1장 미리보기

## 주의

이 저장소에 AI Hub 원본 데이터, 분할 압축 조각, API 키, 계정 정보를 올리지 마세요. AI Hub 안내와 이용 조건에 따라 원본 데이터의 공유·재배포를 피하고, 데이터 설명서와 구축활용가이드에서 라벨 포맷을 확인하세요.
