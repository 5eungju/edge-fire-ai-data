# 지도 지역과 저장 사진 연결

지도 지역(서울·인천·수원·춘천·원주·강릉) 또는 파란 지역 점을 선택하면 해당 지역의 가장 최근 저장 사진을 표시한다. 사진이 없으면 빈 상태를 표시한다. 새로운 사진 입력은 선택 지역을 함께 저장한다. 임의 지도 좌표는 등록 지역으로 오인하지 않도록 사진 입력을 차단한다.

기존 사진은 region_id=NULL인 지역 미지정 자료로 유지한다. 미지정 사진 보기 → 지역에 연결 버튼을 눌러 사용자가 지역을 지정할 수 있다. 이는 사용자 지정 분류이며 실제 촬영 위치·시각이나 2025년 기상/2026년 농도와 같은 사건임을 증명하지 않는다. 실제 센서/카메라 연결은 아직 없다.

SQLite jobs.region_id를 기존 큐에 비파괴 추가한다. 파일과 분석 결과를 복제하지 않고 원본 작업 ID로 지역을 연결한다. 업로드/전환 중 늦게 도착한 다른 지역 응답은 현재 사진을 덮어쓰지 않는다. 실패한 최근 사진은 과거 성공 사진으로 숨기지 않는다. 기존 외부 예시 동영상 자동 재생을 제거했다.

- GET /api/v1/storage/jobs?region=seoul 또는 unassigned
- POST /api/v1/storage/jobs: multipart image와 선택적 region_id
- POST /api/v1/storage/jobs/{job_id}/location: {"region_id":"seoul"}

모든 경로는 기존 API 인증과 같은 출처 프록시를 사용한다. 학습 프로세스와 기존 사진은 삭제하거나 중단하지 않는다.
