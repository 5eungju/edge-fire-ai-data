# 2026년 대기측정 자료 활용

사용자가 제공한 `C:/Users/tmdwn/Downloads/2026.zip`을 읽었다. 내부는 2026년 1~4월 XLSX 4개이며 원본은 변경하지 않았다. 새 데이터·모델·로그는 C의 `outputs/air_quality_2026_v2`에 저장했다. 첫 실험의 중복 키 오류 기록은 v1에 보존했다.

## 정답과 모델의 의미

지역·망·측정소코드·측정소명·측정일시·SO2·CO·O3·NO2·PM10·PM25·주소 열이다. 산불 발생 라벨, H2, VOC, 장비별 화재/비화재 실험 라벨은 없다. 따라서 다음 시간의 실제 CO 측정값을 정답으로 사용하는 농도 회귀 모델을 학습했다. 산불 판정·야외 센서 검증이라고 표시하지 않는다.

CO/SO2/O3/NO2는 에어코리아 열 명명 관례에 따라 ppm, PM10/PM25는 ug/m3로 해석한다. 사용자 파일의 원래 다운로드 URL은 별도로 확인되지 않았으므로 단위는 공식 제공 형식과 대조한 해석이다. 연간 확정 여부와 계측기 특성은 현장 적용 전에 확인해야 한다.

공식 참고:

- https://www.airkorea.or.kr/web/last_amb_hour_data (결측 -999, 연간 확정 전 월보 자료의 변경 가능성)
- https://m.airkorea.or.kr/info/standard/in (오염물질 단위)

## 전처리

전체 1,949,016행을 읽고 서울·경기·인천·강원 725,760행을 대상으로 했다. 동일 측정소/시각 중복 5,760행을 제거한 250개 측정소, 720,000개의 고유 시간 관측을 저장했다. 서로 다른 값이 같은 키에 있으면 원본 값을 conflicts에 기록하고 해당 키의 모든 관측을 학습에서 제외하는 처리를 구현했다. 이 파일에서는 충돌 키가 0개였다.

- -999/음수/비유한 값/빈칸은 결측이며 0으로 바꾸지 않는다.
- 시각 YYYYMMDDHH에서 24시는 다음날 00:00으로 정규화했다. 모든 시각은 KST다. 4월 30일 24시가 5월 1일 00시로 표시될 수 있다.
- CO의 현재·1/2/24시간 전 값과 다음 시간 정답이 실제로 존재하고 시각이 이어지는 경우만 학습한다.
- 다른 물질 결측의 중앙값과 스케일은 학습 분할에서만 계산했다.
- 측정소 숫자 ID를 입력 특성으로 사용하지 않았다. 다른 지역/장비의 일반화 검증은 하지 않았다.

## 비교학습

입력은 현재 CO, 1/2/24시간 전 CO, 현재 SO2/O3/NO2/PM10/PM25, 시간·요일 주기 특성 총 13개다. 정답 시각 기준 3월 24일 이전 train, 3월 24~31일 val, 4월 이후 test로 분리했다. 각각 445,202 / 43,896 / 166,596개다. 미래 측정값은 입력에 넣지 않았다.

딥러닝 MLP(64→32 은닉층)와 히스토그램 부스팅을 검증 MAE로 비교했다. 단순 현재값 유지 모델도 함께 평가했다. 검증 MAE(ppm)는 유지 기준선 0.034386, MLP 0.033973, 부스팅 0.033346이었다. 부스팅을 선택한 후 시험 MAE는 0.027109, 유지 기준선은 0.027550이었다. 개선 폭은 작으며 이 수치를 정확도 백분율이나 산불 감지율로 해석하지 않는다.

## 연동

기존 프론트의 가스 차트 위치에 지역·측정소 선택과 실제 과거 CO/NO2를 표시한다. 두 세로축 모두 ppm이며 H2 자료가 없음을 명시한다. 마지막 24시간 관측과 다음 시간 CO 추정을 표시하며 장비/지도 선택과 자동으로 같은 현장을 의미하지 않는다.

`GET /api/v1/storage/air-quality/stations`와 `GET /api/v1/storage/air-quality/series?station=111121&end=2026-04-30T23:00`를 기존 인증/브라우저 프록시로 읽는다. 조회 범위는 최대 49시간이며 화면에는 24시간을 반환한다. 모델은 서버의 고정 C 경로에서 읽고 SHA256을 확인한다. 사용자 요청으로 모델 파일 경로를 지정하지 않는다. 서버에서 소규모 CO 추론을 수행하며 별도 AI HTTP 서버는 없다.

모델이 기준선을 넘지 못하거나 연속 측정이 부족하면 예측을 출력하지 않는다. 원본 데이터와 모델 파일을 GitHub에 업로드하지 않고 코드·집계 보고서만 반영한다.


다른 결과를 연결하려면 서버 `AIR_QUALITY_ROOT` 환경변수를 해당 C 폴더로 설정한다. 현재 기본은 air_quality_2026_v2다. 완료된 결과를 덮어쓰지 않는다.
