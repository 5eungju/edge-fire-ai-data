공유팀 원본이 아닌 개인 복사본 `codex/storage-worker-integration`에서 작업한다. 모든 새 데이터·모델·로그는 `C:/Users/tmdwn/Documents/Codex/2026-11-19/new-chat/outputs/three_dataset_training_20261123`에 있다. 원본 ZIP과 기존 E 전처리 결과는 읽기만 했다.

## 실제 학습 결과

- 산불 이미지: Colab Tesla T4에서 YOLO26n-seg, 학습 440,207장/회, 검증 79,218장, 3회 설정으로 계속 학습한다. 첫 회차도 아직 완료되지 않았다. 로컬 화면의 영상 추론 모델은 245,696장 시점의 불변 연구 스냅샷이다.
- 화학물질: 실제 TL/VL JSON 18,099건에서 물성 정답을 추출했다. 인화점·연소열·증기압을 예측한다. 가스 농도나 화재 발생 여부를 학습한 것이 아니다. 분자 SMILES 해시로 분할하고 CID가 분할 사이에 겹치지 않는지 추가 확인했다. 구조 별칭/골격 분할 및 단위 검증은 미완료다.
- 물질별 측정 중복은 동일 구조·온도에서 중앙값으로 집계했다. 분자 ID를 수치 입력으로 사용하지 않고 구조 관련 기술자 24개를 사용한다. 증기압·연소열에는 온도를 추가한다. 증기압은 log10 변환값을 출력하며 음의 압력/온도 누락은 제외했다.
- 인화점: 부스팅 선택. 검증 MAE 28.097, 중앙값 기준선 46.141. 시험 MAE 24.564, R² 0.583.
- 연소열: 딥러닝 MLP(96→48 은닉층) 선택. 검증 MAE 411.899, 기준선 2567.801. 시험 MAE 538.235, R² 0.875.
- 증기압: 부스팅 선택. 검증 MAE 1.150, 기준선 2.353. 시험 MAE 1.431, R² 0.561. 오차는 log10 공간이다.
- 위 수치는 정확도 백분율이 아니다. 원자료 단위·측정법 혼합 검토가 남았으므로 연구용이다.
- 대응방안: 정리된 실제 246,272건에 화재 상태·주변시설 정보를 추가해 55개 입력으로 재학습했다. 사건 분리 train 227,264 / val 7,997 / test 11,011이다. 완전 균형 가중치·무가중치·제곱근 가중치를 검증 분할에서 비교했다. 최선 검증 macro F1은 0.2352로 다수 클래스 기준선과 같다. 따라서 위험도 출력은 차단한다. 이전 시험 분할은 이미 평가된 것이므로 새 결과는 회고 실험이며 외부 검증을 주장하지 않는다.
- 대응 문장: 학습 사건의 원천 조건으로 참조 사례 1,500개를 구성했다. 가장 가까운 실제 과거 사례와 원본 ZIP/멤버 출처를 반환한다. LLM 생성·미세조정이나 실시간 대피 지시를 구현했다고 주장하지 않는다. 내부 추론 트리 문장을 학습 입력/정답으로 사용하지 않았다.
- `fire_spread_track` 좌표 목록은 원본에 존재한다. 각 좌표별 측정시각이 없어 시간별 실제 경계/30분 정답으로 쓰지 않았다.

## 재현

복사본 루트에서 다음 명령을 사용한다. 완료된 출력 폴더는 보존하며 재실험은 새 경로를 지정한다.

```powershell
py edgefire_AI/train_three_dataset_extensions.py --output C:/Users/tmdwn/Documents/Codex/2026-11-19/new-chat/outputs/three_dataset_new_run
py edgefire_AI/compare_response_weighting.py --root C:/Users/tmdwn/Documents/Codex/2026-11-19/new-chat/outputs/three_dataset_new_run
py edgefire_AI/register_multi_models.py --model-root C:/Users/tmdwn/Documents/Codex/2026-11-19/new-chat/outputs/three_dataset_new_run --storage-root C:/Users/tmdwn/Documents/Codex/2026-11-19/new-chat/outputs/edgefire_storage_v1
```

학습기는 기본 Downloads의 `38.*`, `57.*` 원본을 읽는다. `--clean-response`는 기존 4단계 전처리 CSV/보고서 폴더이며 기본 E 경로다. 파일을 옮기거나 원본을 덮어쓰지 않는다. 등록은 완료된 두 학습 상태를 확인하고 9개 모델·카탈로그·비교 보고서·참조 자료의 SHA256을 고정한다. 등록 후 모델을 바꾸면 추론이 무결성 오류로 중단되므로 새 결과를 검토해 다시 등록해야 한다. 등록은 연구 결과 사용을 뜻하며 실제 운용 적합성을 보증하지 않는다.

## 저장소 연결

브라우저 → 기존 백엔드 → C의 `assessments/metadata.sqlite` 대기열 → 기존 이미지 작업자 → 결과 JSON 저장 → 브라우저 조회 흐름이다. AI용 별도 HTTP 서버는 없다. 이미지와 통합 분석 대기열을 분리해 JSON을 이미지로 잘못 처리하지 않는다. 기존 큐의 원자적 저장·임대 갱신·오래된 작업자 차단을 재사용한다.

- `GET /api/v1/storage/models`: 실제 모델 등록 및 기준선 통과 상태
- `GET /api/v1/storage/model-examples`: 학습 데이터의 연결 시험용 예시 ID. 성능 평가 자료가 아니다.
- `POST /api/v1/storage/assessments`: `vision_job_id`, 선택 `chemical_cid`, `temperature_c`, `response_features` 또는 `reference_case_id`
- `GET /api/v1/storage/assessments/{job_id}`: 저장된 통합 분석 결과

모든 백엔드 경로는 기존 X-API-Key 인증을 사용하며 브라우저는 서버 프록시 `/api/edgefire/...`를 사용한다. 키를 브라우저에 노출하지 않는다. 입력 키·길이·숫자 유한성·CID·이미지 작업 ID를 검증한다. 요청으로 모델 경로나 임의 파일을 지정할 수 없다.

현재 이미지에 없는 가스 농도·열화상·물질명·현장 상태는 추정하지 않는다. 현재 맥락 입력과 과거 사례 입력은 혼합할 수 없다. 한 JSON에 각 독립 모델 결과를 연결한 것이며 학습된 멀티모달 융합이라고 표시하지 않는다. 불완전한 대응 입력은 INSUFFICIENT_INPUT, 기준선 미달은 REJECTED_FAILED_VALIDATION_BASELINE으로 반환한다.

## 화면 사용

기존 프론트의 왼쪽 카메라 항목을 누르면 분석 창이 열린다. CID를 알고 있으면 입력하고 '저장소 통합 분석'을 누른다. 실제 현장 정보가 없을 때는 대응 위험도를 생성하지 않는다.

'학습 데이터 예시로 연결 시험'을 선택하면 실제 학습 사건의 조건과 예시 물질로 저장소 연결을 검증한다. 화면에 현재 이미지와 다른 사건임을 명시한다. 과거 대응 문장을 현재 장소의 안전 판정이나 자동 신고·방송으로 사용하지 않는다.

## 검증

- 모델 무결성, 결측 입력 거절/보류, 잘못된 CID·경로·비유한 수치 거절
- 기존 업로드·큐 임대·중단 복구·SHA 위변조·인증 계약 검사
- 실제 이미지 결과 + 실제 화학 모델 추론 + 출처가 있는 대응 사례를 C 저장소에 기록하는 종단 시험
- Next.js 프로덕션 빌드와 TypeScript 검사, 실제 브라우저 연결 시험

기준선 미달 모델을 높은 성능으로 표시하거나, 가상의 정답으로 산불 발생/확산 모델이 완성됐다고 표시하지 않는다.
