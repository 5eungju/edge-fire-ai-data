# 파일 업로드·지역 선택 시연

개인 복사본 루트에서 `py integration/run_local.py start`를 실행하고 http://127.0.0.1:3200/ 을 연다. 원본 팀 저장소는 수정하지 않는다. 재빌드 후에는 브라우저를 새로고침한다.

## 사진 입력

오른쪽 카메라 영역의 **사진 입력** 버튼으로 JPEG/PNG/WEBP(10MiB 이하)를 선택한다. 새 입력 사진을 C에 저장하고 SQLite 이미지 작업 큐에 넣는다. 독립 모델 작업자가 분석하면 그 새 작업 ID의 표시 이미지로 교체한다. 다른 이전 완료 결과를 새 사진 결과처럼 표시하지 않는다. 서버 오류/실패는 화면에 표시한다. 왼쪽 카메라 항목으로 해당 사진의 검출 종류와 점수를 확인한다.

미검출은 안전/무화재 판정이 아니다. 이미지로 가스 농도·화학물질 종류·실제 발화 좌표를 만들어내지 않는다. 현재 GPS/카메라 설치 위치 연결은 없으며 지도 선택과 사진 입력은 독립이다. 가스 차트·기존 장비 값은 시연용이다. 실제 카메라 장비는 아직 미정이므로 우선 파일 입력 계약을 사용한다. 장비 자동 촬영·실시간 스트리밍·외부 장비의 네트워크 접속은 아직 구현하지 않았다.

## 정답·예측 비교

왼쪽 카메라 항목 → **화재·비화재 이미지 정답과 예측 비교**를 누른다. 검증 분할(val)에서 클래스와 서로 다른 검토 지점을 기준으로, 추론 전에 선택한 고정 사례 9장을 사용한다. 최종 시험(test) 자료는 접근하지 않았다. 6개 클래스가 포함되며 원본/정답 영역/모델 예측, 놓친 종류·정답에 없는 검출을 나란히 표시한다. 소수 사례의 종류 일치 여부는 박스/마스크 정확도 또는 전체 정확도가 아니다. 현재 중간 스냅샷에서 화염 미검출 사례가 확인되었으며 이를 숨기지 않는다.

로컬 비교 자료는 C의 `outputs/image_comparison_demo_v1`에 있다. 재현 코드는 `edgefire_AI/prepare_comparison_demo.py`다. 기존 manifest가 있으면 덮어쓰지 않는다. 모델을 바꾼 비교는 새 실험으로 관리해야 한다.

## 수도권·강원도 확산 계산

지도 위 지역 메뉴에서 서울·인천·수원·춘천·원주·강릉을 선택한다. 해당 지점으로 지도·발화점·격자가 변경된다. 시각은 2025-12-01~10의 시간 자료 중 선택하며 변경 즉시 재계산한다. **전체 지역 보기**는 기상 대표 지점을 모두 보여준다. 파란 지점을 눌러 해당 지역을 선택할 수도 있다.

**지도에서 발화점 선택**을 누른 후 지도 표면을 클릭하면 그 좌표를 사용한다. 위도 36.8~38.7, 경도 125.8~129.6의 개발용 사각 범위를 검사하며 정확한 행정 경계/토지/식생 판별은 아니다. 가장 가까운 확보 ERA5 격자점의 자료를 적용하고 실제 격자 좌표까지의 거리를 표시한다. 현장 관측 또는 클릭 지점의 정밀 관측이라고 표시하지 않는다.

최근 요청만 지도에 반영하고 이전 격자는 제거한다. 오류 시 이전 결과를 유지했다는 표시를 한다. 캐시는 좌표·시각·알고리즘 버전·기상 원문 SHA에 따라 분리한다. 계산은 평지·균일 연료·가정 확산속도의 미검증 휴리스틱이며 실제 지형·연료·진화·비화를 계산하지 않는다. 실제 화재 발생을 주장하지 않는다.

결과는 C의 `outputs/fire_forecast_202512/requests`에 저장한다. 기존 춘천 고정 결과를 반환하는 GET /forecast는 호환용이며 새 화면은 POST /forecast를 사용한다.

## 제출 설명

사진 입력·이미지 검출·저장소 결과 표시와 과거 대응 사례 조회를 구현한 연구 시제품이다. 일부 화재를 놓치는 중간 모델의 한계와 가스/열화상 미연결, 확산 미검증을 명시한다. 자동 신고·문자·방송은 시연 안내이며 실제 전송되지 않는다.
