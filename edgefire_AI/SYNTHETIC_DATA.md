# 합성 가스 데이터와 화학물질 모듈

## 구분

1. 산불 환경 모델: 실제 AI 허브 산불 대응 자료의 주석 위험 등급을 학습한 기존 기준 모델.
2. 가스 패턴 모델: **전부 허구의 시뮬레이션으로 생성한 데이터**를 학습한 48→24 은닉층 MLP. 실제 센서·산불 자료는 0건입니다.
3. 화학물질 조회: 실제 AI 허브 화학물질 JSON에서 추출한 원시 물성·출처 조회. 위험성 예측 AI 또는 가스 물질 식별 모델은 아닙니다.

세 모듈의 자료는 관측 단위와 의미가 달라 한 학습표로 합치지 않았습니다. 합성 가스의 출력으로 실제 위험 등급을 올리거나 대피/신고를 실행하지 않습니다.

## 합성 데이터 생성·학습

```powershell
py train_gas_demo.py
```

`synthetic_gas_demo.jsonl`: 800개의 독립 시뮬레이션 에피소드에서 8/12/16개 표본 길이의 창을 만든 2,400개 레코드. 각 레코드에 `data_origin=synthetic`, `simulation=true`, 에피소드 ID, 신호 이력, 생성 템플릿에 따른 허구의 정답 라벨을 기록합니다.

패턴은 background(배경), multichannel_rise(다채널 상승), transient_interference(일시적 단일 채널 간섭), sensor_artifact(센서 모사 이상)입니다. 이는 가정한 패턴 이름이며 실제 화재·독성·고장 판정이 아닙니다. CO/H2/VOC 이름은 시연용 신호 채널 구분입니다. 기준값과 측정값은 채널별 같은 임의 단위이며 실제 ppm 보정이나 VOC 물질별 보정이 아닙니다. 임의의 규제/독성/폭발 임계값을 사용하지 않습니다.

입력 특성: 기준값 대비 로그 신호의 최종값·평균·표준편차·초당 변화율·최대 순간 변화. 에피소드별 분리로 학습 1,800개/평가 600개이며 교집합은 0입니다. 같은 생성기의 새 에피소드에서 얻은 성능은 실제 센서 일반화 성능이 아닙니다. 수치는 `gas_simulation_metrics.json`에 기록합니다. 합성 평가 점수를 실측 정확도·산불 탐지 정확도로 보고하지 마세요.

`gas_simulation.joblib`을 만들며 Git에는 올리지 않습니다. 실행 시 `GAS_MODEL_PATH`로 별도 경로를 지정할 수 있습니다. `POST /api/v1/ai/gas/assess`는 `simulation:true`, 양수 baseline, 3~120개 history, 일정한 sample_interval_seconds를 요구합니다. 단위·샘플 간격·기준값의 정의가 다르면 실제 센서에 적용할 수 없습니다.

## 화학물질 카탈로그

```powershell
py build_chemical_catalog.py "C:\Users\tmdwn\Downloads"
```

원천 JSON을 바꾸지 않고 CID별 인화점·증기압·연소열, 측정 온도, 출처를 로컬 `chemical_catalog.json`으로 저장합니다. 이 파생 데이터는 Git에 올리지 않습니다. `CHEMICAL_CATALOG_PATH`로 경로를 지정할 수 있습니다. `GET /api/v1/ai/chemicals/{cid}`로 조회합니다. 원시 값은 단위·시험법·이상치가 검증되지 않아 `units_verified=false`로 반환하며 위험 단계를 산출하지 않습니다.

## 산불 대응 결과와 함께 확인

`POST /api/v1/ai/assess`의 선택 필드 `gas_simulation`에 동일한 합성 시연 요청을 넣으면 `ai.simulated_gas`에 패턴 결과를 별도 반환합니다. 최상위 `risk_level`은 환경 모델 결과만 사용하며, 환경이 없으면 null입니다. 원래 `gas_data`는 실측값 보존용이며 합성 AI로 자동 전달하지 않습니다.

## 실제 모델로 전환하려면

센서 모델명·채널 단위·교정 방식·샘플링 간격을 확정하고, 실제 정상 배경·환경 간섭·연소 상황의 시간별 측정값을 정답 기록과 함께 확보해야 합니다. CO/H2/VOC 세 값만으로 화학물질 종류나 실제 화재 원인을 확정할 수 없습니다. 합성 모델의 현장 성능을 확인하기 전에는 연구·연동 시연에만 사용합니다.
