# 전체 전처리 데이터의 로컬 학습

2026-11-22에 코랩 GPU 사용 한도로 로컬 CPU 학습 경로를 추가했다.
프론트/백엔드 코드는 이 작업에서 수정하지 않는다. 새 학습 모델은 검증 전까지 API 모델로 교체하지 않는다.

## 데이터와 저장공간

- 원본 9개 분할 압축파일은 712,142,501,593바이트(약 663.23GiB)이다. 원본 파일명이 탐색기에 복원된 상태는 아니다.
- 전처리 결과는 600개 ZIP, 598,500장, 약 222.43GiB이다. C와 E의 세 폴더에 분산되어 있다.
- C에 저장된 전처리 ZIP 약 23.3GiB와 C의 남은 공간 약 22GiB는 서로 다른 수치다. 잔여 공간은 실행 중 달라진다.
- 검토 제외 목록을 적용하면 학습 440,207장, 검증 79,218장, 최종 시험 54,826장이다.
- ZIP에서 JPEG와 분할 마스크를 직접 읽는다. 전체 ZIP 해제, 이미지 캐시, 원본 이동·삭제를 하지 않는다.

## 모델과 실제 속도

COCO 사전학습 YOLO26n-seg에서 6개 클래스로 분할 헤드를 변경한다.
검은 연기, 흰색/회색 연기, 불꽃, 구름, 안개/연무, 굴뚝 연기를 구분한다.
가스 센서 모델이나 발화 전 위험 확률 모델의 학습을 의미하지 않는다.

초기 설정: CPU 4스레드, 512픽셀, 배치 2, AdamW, 최대 학습률 0.0001,
100단계 워밍업과 cosine 감소, 초기 실험 3 epoch, 색상·좌우반전 증강.
3 epoch만으로 수렴이나 성능 향상을 보장하지 않는다. 전체 데이터 평가 후 실험을 조정해야 한다.

실제 8단계(16장) 속도 실험: 약 1.84장/초, 전체 학습 1 epoch 약 66시간 예상.
재개 실험은 약 1.54장/초였다. 따라서 1 epoch 약 66–80시간은 짧은 측정에 근거한 추정이며,
전체 검증 시간, 디스크 지연, 발열, 다른 프로그램 사용에 따라 늘어난다.
이 속도 실험은 전체 학습 완료나 성능 평가가 아니다. 코랩 할당량을 우회하지 않는다.

## 실행

현재 작업공간에서 다음처럼 실행한다. 경로는 해당 노트북 기준이다.

```powershell
py work/EDGEFIRE-personal/edgefire_AI/train_full_stream.py --workspace . --run outputs/full_cpu_training_20261122
```

중단된 학습은 같은 옵션에 `--resume`을 추가한다. 모델뿐 아니라 AdamW 상태, epoch 안의 이미지 위치,
shuffle seed와 RNG 상태를 복원한다. epoch 중간 저장을 다음 epoch로 잘못 처리하지 않는다.
`last.pt`는 5단계 후, 이후 약 120초마다, epoch 종료 시 임시파일 쓰기·fsync·원자 교체로 저장한다.
프로세스 종료나 전원 손실 시 마지막 저장 이후 작업은 다시 처리한다.

실행 폴더에 `STOP`이라는 파일을 만들면 현재 배치를 마치고 저장 후 정지한다.
재개 전 STOP 파일을 제거해야 한다. 노트북 절전·종료·SSD 분리는 학습을 멈추게 한다.

`status.json`은 단계, 현재 epoch 처리 장수, PID, 마지막 손실, 실제 처리속도를 기록한다.
`config.json`, `data_policy.json`, `code_snapshot/`은 설정·데이터 식별자·사용 코드를 보존한다.
코드 변경 후에는 원래 `code_snapshot/train_full_stream.py`로 재개한다.
서로 다른 코드/데이터/학습 설정으로 기존 체크포인트를 무단 재개하지 못하도록 검사한다.
현재 실행기는 CPU용이다. 코랩에서 이어 학습하려면 해당 데이터 접근 경로와 GPU 실행기를 별도 구성해야 한다.
체크포인트만 코랩에 올린다고 E드라이브 데이터에 접근할 수 있는 것은 아니다.

## 품질 및 평가 관문

`full_zip_dataset.py`는 제외 목록의 의미 해시, 검토 링크, ZIP 목록과 검사 당시 파일 크기·수정시각,
검사 결과의 corpus 해시를 확인한다. 각 이미지 읽기 시 ZIP CRC와 검사된 JPEG SHA256을 다시 확인한다.
시작 때 222GiB 전체를 다시 해시하는 것은 아니므로 저장장치 오류가 재발하면 무결성 검사를 다시 해야 한다.
검토 제외 항목은 어떠한 split으로도 이동하지 않는다. 기존 V4 차단 정책을 해제하지 않는다.

매 학습 epoch 완료 후 검증용 79,218장 전체로 라이브러리의 box/mask 지표를 계산한다.
검증 도중 중단되면 체크포인트로 재개해 해당 검증을 다시 한다.
시험용 54,826장은 모델 선택에 사용하지 않는다. 후보 비교와 선택을 마친 뒤 별도로 한 번 평가해야 한다.
자동 서비스 배포, 최고 모델 선정, 공식 정확도 확정은 이 실행기가 수행하지 않는다.

검증: 제외 목록/분리 집합 적용, 변조 JPEG 거부, 결정적인 증강, optimizer·epoch 위치 복원 테스트.
실제 YOLO 모델에서도 5단계 체크포인트에서 8단계까지 재개한 마지막 손실이 원래 실행과 일치했다.
2장 검증 smoke test는 배선 확인용이며 모델 성능 수치로 보고하지 않는다.
