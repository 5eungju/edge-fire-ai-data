# 산불 대응방안 데이터 준비

`prepare_response_data.py`는 원천 ZIP 28개와 라벨 ZIP 28개를 읽으며,
사건·위치·시간 파일명을 기준으로 원천과 정답을 연결한다. 파일 이름의 S/T
표시만 대응시키고 사건 ID도 원천 내부 정보와 대조한다. 원본은 수정하거나
전체 압축 해제하지 않는다.

입력은 원천의 기상 10개, 지형 7개, 연료 6개 숫자 항목으로 제한한다.
정답은 라벨의 `countermeasures.immediate_recommendation.risk_level`이다.
이는 데이터에 주석된 대응 위험도이며, 실제 발화 확률이나 안전 판정 정답을
뜻하지 않는다. 사건 종료 시각·최종 피해 면적·생성된 추론 설명·정답은
입력 특성에 포함하지 않는다. 사건 ID·질문·시간은 추적 메타데이터이며,
현재 숫자 모델의 입력이 아니다. 물성 단위와 0으로 기록된 연료 값의 의미는
별도로 검토해야 한다.

```powershell
py edgefire_AI/prepare_response_data.py --source "C:/Users/tmdwn/Downloads/38.산불 확산 위험 대응방안 추론 데이터" --output E:/AI_Work/edgefire_response_v1
py edgefire_AI/audit_response_data.py --root E:/AI_Work/edgefire_response_v1
```

SQLite에 출처·원천/라벨 SHA256·23개 특성·주석 정답을 저장한다. 원천 ZIP
단위로 커밋하며 완료한 묶음은 재실행 시 건너뛴다. 원본 묶음의 크기나 수정
시각이 달라지면 중단한다. ZIP 내 정답 키 중복과 누락, 파일명·사건 ID
불일치 등을 정상 학습 사례로 숨기지 않는다.

품질 감사는 제공된 train/validation 사이의 사건 중복, 동일 숫자 입력의
반복과 서로 다른 정답, 클래스 분포, 결측을 조사한다. 사건 ID의 고정 해시로
새 train/val/test 후보를 구성하고 사건 하나가 여러 분할에 들어가지 않게
한다. 클래스가 하나뿐이거나 분할에 정답 클래스가 빠지면 보고한다.

감사 완료만으로 `training_ready`를 참으로 바꾸지 않는다. 중복 제거·충돌
검토와 정답 의미·단위·연료 결측 검토를 거쳐야 모델 비교를 시작할 수 있다.
주석의 신뢰도 숫자를 모델의 보정된 확률로 사용하지 않는다. 현재 코드는
대응방안 문장 생성이나 실제 대피·안전 판단을 자동 실행하지 않는다.
