# 모델 비교 실행과 선정 기준

현재 서비스 모델은 첫 번째 산불 표본 모델입니다. 이전 카메라 기준 실험은 공간 독립 평가가 아니므로, 새 엄격한 비교는 검사를 통과한 공간 분리 V4 데이터와 일반 사전학습 가중치로 시작합니다.

## 후보

| 후보 | 준비한 일반 사전학습 모델 파라미터 | 비교 이유 |
|---|---:|---|
| YOLO26n-seg | 3,126,280 | 현재 계열의 작은 분할 모델을 엄격한 데이터에서 다시 검증 |
| YOLO11n-seg | 2,876,848 | 다른 세대의 작은 분할 모델과 정확도·CPU 지연을 실제 비교 |

위 수는 COCO 80클래스 가중치의 실측값입니다. 산불 6클래스로 머리를 바꾸면 수가 달라지며 최종 실험 결과에 다시 기록합니다. COCO 성능이 산불 성능을 보장하지는 않습니다. 일반 가중치의 SHA256은 generic_pretrained_manifest.json에 고정했습니다. 기존 산불 모델을 새 공간 실험의 초기 가중치로 사용하지 않습니다.

공식 모델 설명: https://docs.ultralytics.com/models/yolo26/ 및 https://docs.ultralytics.com/models/yolo11/

## 비교 조건

공통 학습 2,543장·검증 490장, 입력 512, 배치 4, CPU 6스레드 요청, 최대 12 epoch, 같은 초기 seed와 AdamW 설정을 사용합니다. 검증 개선이 없으면 동일 patience=5 규칙으로 조기 종료하므로 실제 반복 수·계산량은 다를 수 있습니다. 실험은 순차 실행합니다.

새 비교에서는 warmup_bias_lr=0.0을 명시합니다. 설치된 Ultralytics의 자동 optimizer 설정도 bias 워밍업을 0에서 시작하므로, 명시적으로 선택한 AdamW에 이 조건을 적용합니다. 이미 진행 중인 두 번째 실험의 설정은 바꾸지 않습니다. 실제 optimizer 설정과 라이브러리 버전은 각 결과에 기록합니다.

실험 시작 시 학습 코드·검증 관문·상태 기록 코드·가중치 목록·선정 코드를 code_snapshot에 복사하고 SHA256으로 고정합니다. 두 후보는 같은 스냅샷으로 실행하며, 완료 결과를 재사용할 때도 데이터·코드·설정 일치를 확인합니다. 저장소의 이후 편집이 진행 중인 비교의 두 후보에 서로 다르게 적용되지 않게 합니다.

선정 점수는 고정 confidence=0.25에서의 마스크 지표로 계산합니다.

선정용 P/R/F1은 Ultralytics 검증 곡선에서 0.25에 가장 가까운 격자점의 근삿값입니다. 서비스 API의 실제 필터 기준은 0.25입니다.

- 연기·화염 3종 평균 F1 × 0.8
- 전체 6종 평균 F1 × 0.2

최고 점수와 0.01 이내인 후보 중 검증 이미지 20장의 단일 CPU 스레드 p95 처리 시간이 짧은 후보를 택합니다. 이는 미리 정한 연구용 절충 규칙이며 통계적 동등성이나 모든 모델 중 최적임을 뜻하지 않습니다. 벤치마크에는 로컬 이미지 로드·모델 처리·다각형 변환을 포함하며 HTTP·대기열 지연은 제외합니다.

모델 선정 함수는 시험 분할 결과나 서로 다른 검증 표본을 거부합니다. 각 후보 학습 종료 후 검증만 다시 평가하고, 후보를 선택한 뒤 선정 모델의 시험 531장을 평가합니다. 시험 결과로 후보 순위를 다시 고르지 않습니다. 결과는 운영 가능 판정이 아니며 실제 서비스 모델 교체는 별도 검토합니다.

## 실행

```powershell
py edgefire_AI/run_model_comparison.py --validate-only
py edgefire_AI/run_model_comparison.py
```

기존 학습을 보존하면서 다음 비교를 대기시킬 수 있습니다. wait-pid는 현재 실제 학습 프로세스의 번호이며, 대기 상태 파일이 완료인지도 확인합니다. 이전 학습이 실패하면 새 작업을 자동으로 겹쳐 실행하지 않고 검토할 수 있게 멈춥니다.

```powershell
py edgefire_AI/run_model_comparison.py --wait-pid PROCESS_ID --wait-status PATH_TO_STATUS_JSON
```

결과는 E:/AI_Work/edgefire_spatial_comparison_v1에 저장합니다. 완료 후보의 결과는 같은 설정·데이터일 때 재사용하며 부분 실패 후보는 로그·체크포인트를 확인해 재개해야 합니다. 실행 상태는 status.json 또는 --status 경로에 기록합니다.

공간 데이터의 파일 검사·유사도 검사 결과가 없거나 오래됐거나 미해결 후보가 있으면 학습 관문이 거부합니다. 데이터와 가중치 해시를 검사하며 공간 분리 체크포인트 재개 시 데이터 경로·기록된 데이터 해시가 같아야 합니다.

두 후보 모두 실제 18장으로 1 epoch, 검증 9장만 사용하는 작은 실행 점검을 완료했습니다. 이 점검은 학습·가중치 저장·검증 전용 평가·벤치마크·선정 함수 연결의 동작 검사이며 인식 성능의 증거가 아닙니다. 시험 이미지는 예측하지 않았습니다.
