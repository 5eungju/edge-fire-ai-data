# 전체 산불 이미지 전처리 확대

기존 3,564장은 예비 비교용 표본이다. 전체 원본을 전처리한 크기가 아니며,
현재 GPU 표본 실험과 다음 전체 데이터 준비를 구분한다.

## 전체 후보 목록 검사 결과

- 원본 이미지 항목: 630,000개
- 압축 오류 제외: 13개
- 이미지 디코딩·라벨 검증 전 후보: 629,987개
- 학습 후보: 462,774개
- 검증 후보: 85,704개
- 시험 후보: 81,509개
- V4 장소 분할 계획 SHA256: `812084b3a1766e567365eec522e4ae81514ebed3c38a53984fcdd04b399bd171`
- 전체 후보 목록 SHA256: `3279284f09945c000e65676c010ab5c9b5a46a0aeb0b65ce47fcb6ab4f128d39`

이 숫자는 학습 준비가 끝난 이미지 수가 아니다. 후보 목록은 영상·라벨 ZIP의
파일 연결과 기존 장소 그룹 배분을 확인한 결과다. 전체 픽셀 디코딩, 마스크
기하 검사, 중복 검사를 통과한 수량은 실행 결과에서 별도로 집계한다.

## 재현

```powershell
py edgefire_AI/build_full_inventory.py --output E:/AI_Work/edgefire_full_inventory_v1
py edgefire_AI/preprocess_full_inventory.py --inventory E:/AI_Work/edgefire_full_inventory_v1/full_source_inventory.jsonl --output E:/AI_Work/edgefire_full_export_v1 --budget-gib 180 --min-free-gib 50
```

전처리는 원본을 수정하지 않고 1,000개 단위 ZIP에 이미지·YOLO 라벨·원본
JSON·출처 목록을 저장한다. 원본 이미지의 SHA256 중복은 제외한다. 픽셀
디코딩, 치수·카메라 ID·파일명·클래스·다각형 검사를 거치며, 알려진 파일명
오타 규칙 외에 정답을 추측하거나 마스크를 임의로 수정하지 않는다.

이미지는 종횡비를 유지하여 최대 변 1280px, JPEG 품질 90으로 저장한다.
이는 작은 연기의 세부 정보 손실 가능성이 있으므로 크기별 평가가 필요하다.
장면의 연속 프레임은 전체 전처리 단계에서 예비 실험의 프레임 간격·클립별
개수 제한을 적용하지 않는다. 중복·유사 프레임 조사 후 학습 표본 구성을
결정해야 하며, 파일 수가 독립적인 장면 수를 뜻하지 않는다.

180GiB 출력 또는 50GiB 미만의 여유 공간에 도달하면 저장공간 제한으로
멈춘다. 이미지 개수 제한은 기본값 0(무제한)이다. 따라서 저장공간 제한에
걸리면 전체 이미지 출력은 완료되지 않는다. 같은 명령을 재실행하면 완료된
ZIP과 SQLite 기록을 이용해 이어간다. 중단 당시 `.partial` 파일은 보존하며
완료된 ZIP으로 취급하지 않는다. 확정된 ZIP 내부 목록으로 DB 커밋 직전
중단도 복구한다. 저장 장치 I/O 오류는 정상 제외 이미지로 숨기지 않는다.

## 학습 전 남은 검사

출력 완료는 학습 승인과 같지 않다. 전체 데이터의 교차 분할 유사 배경 조사,
최종 파일/라벨 검증, 데이터 비율과 누락 분석, 저장용량 및 GPU 접근 경로
구성이 추가로 필요하다. 새 데이터는 기존 코랩 표본 학습에 자동으로 섞지
않는다. 시험 데이터는 모델 선택에 사용하지 않는다.

## 추가 텍스트·화학 데이터 초기 구조 확인

로컬 압축파일 목록을 확인했다. 산불 대응방안 데이터는 ZIP 56개에 파일
493,578개, 화학 데이터는 ZIP 12개에 파일 54,297개가 들어 있다. 이는 중복
제거 후 학습 사례 수가 아니다.

대응방안 원천 JSON 표본에는 기상·지형·연료·사회기반 정보가 있으며, 라벨
표본에는 질문과 위험 평가·대응 관련 정보가 있다. 산불 사건 종료 시각과
최종 피해 면적 등 결과 정보는 미래 예측의 입력에 넣으면 누출이 발생할 수
있다. 사건 단위 분리와 입력 시점 확인이 필요하다. 발생한 산불의 대응
데이터만으로 미발생 지역의 발화 확률을 학습했다고 주장할 수 없다.

화학 라벨 표본에는 물질 구조(SMILES), 증기압·연소열·인화점 항목이 있다.
결측값과 단위·출처 검토가 선행돼야 한다. 물성 예측과 실제 가스 센서
감지는 다른 문제이며, 실제 가스 감지 모델 학습이 완료된 것은 아니다.
